详情页统计图修复方案

文件：DetailActivity.kt — setupBarChart() 方法 | 修改范围：Y轴 + X轴 + 柱状图数值格式

一、问题分析

问题1：纵坐标无等分线，单位不统一

Y轴未做任何配置，默认显示原始秒数（0~24000），数值标签混用 "h" 和 "s"（如 3.7h、613s），无法直观比较各天差异。

问题2：横坐标日期过长导致重叠

X轴使用完整日期格式 "yyyy-MM-dd"（如 2026-09-10），当数据点较多时日期文字严重重叠。

二、修复方案

修复1：纵坐标改为等分线（单位：小时）

改动 将柱状图数据从"秒"改为"小时"（秒数 / 3600）

改动 配置 axisLeft：6等分线，范围 0 至向上取整的最大值

删除 禁用右侧 axisRight（当前镜像显示无意义）

修复 柱顶数值统一显示为小时格式（如 3.7h、0.2h）

等分线范围计算逻辑：

步骤说明示例
1. 找最大值所有柱数据的最大小时数6.2h
2. 向上取整Math.ceil(maxHours)7h
3. 设等分线axisMinimum=0, axisMaximum=7, labelCount=70, 1, 2, 3, 4, 5, 6, 7
4. 特殊处理若最大值 < 1h，则按0.5等分0, 0.5, 1.0

修复2：横坐标日期简化 + 防重叠

改动 日期格式从 "yyyy-MM-dd" 改为 "MM-dd"（如 09-10）

改动 X轴标签旋转 -45°

改动 限制标签数量，最多显示 6 个，自动跳过

改动 启用 setAvoidFirstLastClipping 防止首尾裁剪

效果对比：

数据点数量当前显示修复后显示
8个2026-09-10 ~ 2026-09-25（重叠）09-10, 09-12, 09-14... （最多6个，-45°旋转）
3个2026-09-10 ~ 2026-09-12（可能重叠）09-10, 09-11, 09-12（全部显示，-45°旋转）
